MailVault v1.2.0

Application details

Settings

Offline mode. Intake verifies multipart order, hashes each source ZIP, preserves the originals, and writes dated EML files beneath the selected account archive.

Dependencies

  • WebView2 Runtime
  • Writable archive destination
  • Takeout ZIPs containing Mail MBOX or EML entries

Requirements

Windows x64, enough free space for expanded mail, and an operator-supplied account identity.

Credentials

None. MailVault does not connect to Google.

Diagnostics

Each import writes source hashes, byte counts, multipart evidence, and entry failures under Gmail\_TakeoutReceipts.
